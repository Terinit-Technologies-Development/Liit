# PR-01: LIIT Design Foundation, App Shells, Onboarding, and Profile Review & Walkthrough

## 1. Executive Summary & Objective

This pull request completes **LIIT INSTRUCTION 1 OF 9 — FOUNDATION, NAVIGATION, ONBOARDING, AND CONSUMER IDENTITY**.

It establishes the architectural and visual foundation for LIIT's advanced prototype using the **Midnight Kinetic** design system. It builds the complete first-launch onboarding sequence (`(public)/welcome`, `(public)/location`, `(public)/interests`, `(public)/sign-in`), restyles the consumer profile (`(consumer)/profile`), creates settings & preferences (`(consumer)/settings`), saved events (`(consumer)/profile/saved`), activity history (`(consumer)/profile/activity`), mode switcher modal (`(modals)/mode-switch`), light session boundary (`useSessionStore`), and design system component showcase library (`(modals)/component-preview`).

## 3. Setup & Deterministic Walkthrough

### Local Environment Reset
1. Run `npm run start` and open the web/mobile app.
2. Open **Prototype Controls** (gear icon in header) and tap **"Reset All Prototype State"**.
3. Relaunch app: App routes automatically to `(public)/welcome`.

### Reviewer Walkthrough Steps
| Step | Action | Expected Outcome |
| :--- | :--- | :--- |
| **1. First Launch** | Launch freshly reset app. | App presents `(public)/welcome` with double-dot motif & 3 stepper panels. |
| **2. Stepper & Guest** | Tap "Next" or "Continue as Guest". | Navigates to `(public)/location`. |
| **3. Location Selection** | Tap "Use My Location" or select "Johannesburg". | City state updates to Johannesburg; tap "Continue" to navigate to `(public)/interests`. |
| **4. Interest Tags** | Select interest chips (Music, Nightlife, Art). | Chip count badge updates dynamically; tap "Continue". |
| **5. Simulated Sign-In** | Tap "Simulate Sign In" (or "Continue as Guest"). | Session state updates, onboarding marks complete, routes to `(consumer)/feed`. |
| **6. Profile Navigation** | Tap Profile tab in bottom bar. | Renders `(consumer)/profile` with avatar, handle `@thabo_m`, stats (14/8/32), and saved events. |
| **7. Segmented Tabs** | Tap "Saved", "Activity", "Attended". | Content switches between saved events, activity timeline, and empty attended state. |
| **8. Settings** | Tap gear icon in top right of Profile. | Renders `(consumer)/settings` with interactive setting rows and toast notifications. |
| **9. Mode Switch** | Tap "Switch to Creator Mode". | Opens `(modals)/mode-switch` modal; selecting Creator mode switches app to Creator shell. |
| **10. Component Showcase** | Open `(modals)/component-preview`. | Renders typography tokens, `GlassSurface`, `GradientButton`, `SecondaryButton`, `StatusPill`, `PrototypeBadge`, and form fields. |
