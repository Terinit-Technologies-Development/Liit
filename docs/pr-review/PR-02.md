## 3. Architecture & Domain Changes Summary

1. **Route Contracts & Bottom Tabs**:
   - `ROUTES.consumer.search` (`/(consumer)/search`) and `ROUTES.consumer.notifications` (`/(consumer)/notifications`) registered as contextual routes.
   - `CONSUMER_TAB_ROUTES` exported from `src/navigation/routes.ts`. Bottom navigation in `app/(consumer)/_layout.tsx` maps over `CONSUMER_TAB_ROUTES` preserving exactly five visible tabs (`feed`, `explore`, `map`, `tickets`, `profile`) by setting `href: null` for `search`, `notifications`, and `settings`.

2. **Event Domain & High-Resolution Image Registry**:
   - `Event` model extended with `heroImageKey: ImageAssetKey` and `galleryImageKeys: ImageAssetKey[]`.
   - `imageRegistry` (`src/assets/image-registry.ts`) maps strongly-typed image keys to local asset binaries under `assets/images/`. All 19 high-resolution asset files possess distinct SHA-256 hashes verified by `AssetIntegrity.test.ts`.

3. **Explore Empty State & Presentation**:
   - `isExplorePayloadEmpty` checks if all 5 collections are empty. When true, `ExploreScreen` renders `EmptyState` ("Nothing to explore yet") and suppresses all collection section headers.

4. **Scenario Transformations & Johannesburg Weekend Range**:
   - `applyEventScenario` and `applyFeedScenario` modify repository outputs according to `useAppStore.scenario` (`empty_discovery`, `sold_out`, `live_event`, `normal`). `applyFeedScenario` transforms only the first Feed Event.
   - `getWeekendRange` computes Friday 00:00 SAST to Monday 00:00 SAST using fixed UTC+2 offset arithmetic, preserving the active weekend when called on Saturday or Sunday.
