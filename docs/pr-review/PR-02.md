## 3. Architecture & Domain Changes Summary

1. **Route Contracts & Bottom Tabs**:
   - `ROUTES.consumer.search` (`/(consumer)/search`) and `ROUTES.consumer.notifications` (`/(consumer)/notifications`) registered as contextual routes.
   - `CONSUMER_TAB_ROUTES` exported from `src/navigation/routes.ts`. Bottom navigation in `app/(consumer)/_layout.tsx` maps over `CONSUMER_TAB_ROUTES` preserving exactly five visible tabs (`feed`, `explore`, `map`, `tickets`, `profile`) by setting `href: null` for `search`, `notifications`, and `settings`.

2. **Event Domain & Image Registry**:
   - `Event` model extended with `heroImageKey: ImageAssetKey` and `galleryImageKeys: ImageAssetKey[]`.
   - `imageRegistry` (`src/assets/image-registry.ts`) maps strongly-typed image keys to local asset binaries under `assets/images/`. All 19 asset files possess distinct SHA-256 hashes verified by `AssetIntegrity.test.ts`.

3. **Presentation Adapter**:
   - `getEventDisplayStatus(event, nowIso)` derives marketing status (`Live`, `Selling Fast`, `Sold Out`, `Free`, `Upcoming`, `Completed`, `Cancelled`) deterministically based on `DEMO_NOW_ISO` (`2026-07-30T20:00:00.000Z`).
   - Minor currency amounts are formatted once without pre-dividing by 100 before calling `formatCurrency`.

4. **Scenario Transformations & Filters**:
   - `applyEventScenario` and `applyFeedScenario` modify repository outputs according to `useAppStore.scenario` (`empty_discovery`, `sold_out`, `live_event`, `normal`).
   - Search predicate includes date preset matching (`any`, `today`, `tomorrow`, `this_weekend`) and Haversine metric distance calculation from Johannesburg city centre (`-26.2041, 28.0473`).
