# PR-05 — Inbox, Direct Chat, Host Inquiries, and Social UI

## Objective

Build the LIIT consumer messaging and social coordination surfaces:
1. Inbox (`(consumer)/inbox`) with Direct and Hosts & Events (Inquiries) tabs.
2. Direct thread (`(consumer)/inbox/direct/[conversationId]`) based on `liit_chat_with_alex` with presence, status indicators, typing state, composer, and block/unblock actions.
3. Host inquiry thread (`(consumer)/inbox/inquiries/[conversationId]`) based on `liit_inquiry_club_vibez` with verified host badge, typical reply time, sticky event context card, and direct booking offer card.
4. Social modules (`ReactionBar`, `CommentRow`, `CommentComposer`) for feed/event posts.
5. Modals: `new-message`, `conversation-actions`, `report-content`.
