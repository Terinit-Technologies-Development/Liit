## Objective

Establish LIIT's primary conversion journey from Map discovery to selected Event preview, canonical Event Detail, and public Host Profile, while preserving the accepted 5-tab Consumer shell.

## Architecture

- Reusable domain schemas and models (`src/domain/map`, `src/domain/event-detail`, `src/domain/hosts`)
- Pure visual adapter (`MockMapAdapter`) for geospatial projection & cluster node building
- Data-driven module flags and pure conversion model mapping (`getEventConversionModel`)
- Repositories with simulated async operation boundaries (`MockMapDiscoveryRepository`, `MockEventRepository`, `MockHostRepository`)
- Persisted Zustand state (`useMapDiscoveryStore`, `useDiscoveryStore`)
- Shared saved event (`savedEventIds`) and followed host (`followedHostIds`) state

## Map adapter boundary

- Maps coordinates within `JOHANNESBURG_BOUNDS` `[-26.27, -26.13, 27.88, 28.12]`
- Zoom 1–2: Combines points sharing `clusterKey` into `MapClusterNode`s
- Zoom 3: Expands into individual `MapEventNode` pin nodes
