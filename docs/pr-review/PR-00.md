# PR-00: LIIT Application Foundation Review & Walkthrough

## 1. Executive Summary & Objective

This pull request establishes the core frontend foundation for the LIIT advanced prototype in accordance with **LIIT INSTRUCTION 0 — APPLICATION BOILERPLATE AND IMPLEMENTATION FOUNDATION**.

It creates a mobile-first, production-shaped React Native application using Expo SDK 57, TypeScript, Expo Router, TanStack Query, Zustand, React Hook Form, and Zod. It sets up domain entities, mock repository contracts, design token architecture (Midnight Kinetic theme), typography font loading (`Plus Jakarta Sans` and `Syne`), shared UI primitives, dev scenario controls, accessibility controls, test suite, and CI workflow.

**Scope Boundary**: No final consumer or creator screens, Stitch page implementations, Supabase integrations, or Instruction 1 features are included in this PR.

## 2. Setup & Reset Instructions

### Local Environment Setup
```bash
# 1. Install dependencies
npm install --legacy-peer-deps

# 2. Start Expo Development Server
npm run start

# 3. Launch Web or Native Target
npm run web
```

### Deterministic Reset Steps
1. Navigate to **Prototype Controls** (gear icon in header or mode chip).
2. Tap **"Reset All Prototype State"**.
3. All Zustand state, scenario overrides, and AsyncStorage keys (`liit-prototype-state-v1`) are reset to baseline defaults.
