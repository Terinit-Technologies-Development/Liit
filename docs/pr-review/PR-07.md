## 5. Assumptions & Deliberate Deviations

1. **Seeded wallet tickets are demo history** — Event Detail shows "View your pass / View your ticket" only for session-created bookings (non-`ticket-liit-seed-*`), preserving the accepted "Choose tickets"/"Register free" checkout entry flows.
2. **Inquiry fixtures use host identities distinct from discovery hosts** — the seeded `conv-inquiry-club-vibez` / `conv-inquiry-soweto-market` fixtures remain as inbox history; canonical event/host entry points use `getOrCreateInquiryContext`, which deterministically creates the matching host+event conversation (idempotent across Event Detail, Host Profile, New Message, Inquiry Thread, and Notifications).
3. **Simulated host reply resolution by canonical context** — `getPrototypeHostReply(conversation)` resolves the canned reply from the inquiry's `hostId` (+ optional event-scoped refinement) instead of exact seeded conversation ids, covering every canonical discovery host (`host-groove-co`, `host-jozi-vibe-tribe`, `host-art-hub-jhb`, `host-amapiano-pulse`) plus the seeded fixture hosts (`host-club-vibez`, `host-soweto-collective`). `maybeSchedulePrototypeHostReply` only begins typing when a deterministic reply exists for that conversation, so no typing animation is ever followed by silence. Once-per-reset is preserved per canonical conversation id; unknown hosts produce no reply and no typing.
4. **Unknown tier ids** — persisted inventory is enforced for canonical seeded tiers; quotes against unknown tiers are treated as unlimited so legacy test fixtures keep working.
5. **Comment failure toggle** — fails the first post per `clientMutationId`; retry after toggling off succeeds (unchanged).
6. **Web static export** — pre-existing Node-SSR limitation (AsyncStorage in the static renderer); Android Hermes bundle export succeeds (verified).
7. **Lint** — 21 warnings (0 errors): 15 pre-existing repo warnings + 6 accepted `no-require-imports` warnings in test mock factories / `require("react")` router mocks, matching the standing Instruction 5 pattern.
