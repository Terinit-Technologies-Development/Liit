## Fee policy

```
RATE = 500 bps (5.00%)
fee  = Math.round(subtotalMinor × 500 / 10_000)
fee  = 0 when subtotalMinor = 0 (free event)
```

## Checkout architecture

```
Event Detail (Get Tickets / Register Free)
  ↓ beginCheckout() + navigate
Ticket Selection
  ├─ free:  tryBeginFreeRegistration() → createFreeRegistration() → repository exclusive queue → invalidate queries → Result (free_success)
  └─ paid:  setQuote() → navigate
Payment
  ↓ tryBeginAttempt(attemptId) → navigate (atomic guard, rejects duplicate press)
Processing
  ↓ usePaymentSimulationMutation() → invalidates ticketing cache
  ├─ paid:          clearCheckout() → Result (paid_success)
  ├─ declined:      releaseAttempt() → Result (declined)
  └─ network_error: releaseAttempt() → Result (network_error)
Result
  ├─ paid_success:  isMatchingSuccessOrder → View Ticket | Wallet | Share | Back to Feed
  ├─ free_success:  isMatchingSuccessOrder → View Pass | Wallet | Add to Calendar | Share | Back to Feed
  ├─ declined:      Try Again | Change Payment Method
  └─ network_error: Retry | Return to Event
```
