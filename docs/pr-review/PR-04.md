`handlePrimaryAction` now navigates for `paid` and `free_registration` modes:
- **paid**: `beginCheckout(eventId, tierId)` → `routeBuilders.checkoutTickets(eventId, tierId)`

- **waitlist**: unchanged toast

## Fee policy

```
RATE = 500 bps (5.00%)
fee  = Math.round(subtotalMinor × 500 / 10_000)
fee  = 0 when subtotalMinor = 0 (free event)
```

## Checkout architecture

```
Event Detail
  ↓ beginCheckout() + navigate
Ticket Selection (transient quantities, buildCheckoutQuote)
  ↓ setQuote() + navigate
Payment (select method)
  ↓ beginAttempt(nanoid()) + navigate
Processing (useRef-guarded single simulatePayment call)
  ↓ setLatestAttempt() + replace
Result (paid_success | free_success | declined | network_error)
  ↓ navigate to wallet or retry
```

## Payment simulation

`MockTicketingRepository.simulatePayment()`:
- `scenario === "payment_decline"` → `declined`
- `scenario === "payment_network_error"` → `network_error`
- all other scenarios → `paid`

On `paid`: creates `TicketOrder` + `WalletTicket[]` and persists to `AsyncStorageTicketingStorage`.

## Duplicate-submit protection

`useCheckoutStore.beginAttempt(attemptId)` stores the active attempt ID. Processing uses `useRef(false)` to guard against double-invoke from React Strict Mode.

## Order and Ticket lifecycle

```
simulatePayment → PaymentAttempt { status: "paid" }
               → TicketOrder { status: "paid" }
               → WalletTicket { status: "valid", entryMode: "qr_placeholder" }

createFreeRegistration → TicketOrder { status: "free_confirmed" }
                       → WalletTicket { status: "valid", entryMode: "profile_verification" }
```

## Manual reviewer walkthrough

### Paid journey
1. Explore → Midnight Kinetic Grooves → **Get Tickets**
2. Ticket Selection → increase General Access quantity → **Continue**
3. Payment → Demo Visa 4242 pre-selected → **Pay R…**
4. Processing spinner → auto-advances
5. **Tickets confirmed!** → View my ticket
6. Full Ticket screen with QR placeholder badge and valid status

### Free journey
1. Explore → Soweto Street Food & Craft Market → **Register Free**
2. Ticket Selection (Register mode) → Free Registration qty = 1 → **Confirm Registration**
3. **Registration confirmed!** → Go to Wallet
4. Full Ticket → Profile Verification badge, no QR

### Decline journey
1. Prototype Controls → set scenario **Payment Decline**
2. Paid journey steps 1-3 → Processing → **Payment declined** result
3. Try again → returns to Payment screen

### Network-error journey
1. Prototype Controls → set scenario **Payment Network Error**
2. Paid journey steps 1-3 → Processing → **Something went wrong** result

### Wallet and status review
1. My Wallet → Upcoming tab shows seed tickets
2. Tap a ticket → Full Ticket screen
3. Past tab → used/cancelled tickets appear there
